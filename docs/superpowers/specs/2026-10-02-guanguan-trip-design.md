## 1. 目标与成功标准

**目标**：做一个纯静态、可交互、像 PPT 一样翻页的网页，以罐罐（鼠兔玩偶）的第一人称视角，记录 2026.9.26–10.3 的青甘之旅，并感谢一路给它拍照的人（晨阳）。

**成功标准**
1. 打开网页能看到 10 页内容，用键盘 / 点击 / 触屏翻页，切换时有转场动效。
2. 图片、文案、聊天记录正确落在对应日期的页面上。
3. 通过 GitHub Pages 得到一个公网链接，手机、电脑上都能正常浏览。
4. 整体是「可爱卡通风 + 蓝绿黄多巴胺配色」，与参考模版 `template.html` 风格一致。
5. 中文字体自托管，国内访问不依赖 Google Fonts。

**约束**
- 纯静态：无后端、无构建步骤、无数据库。
- 图片与字体需要压缩/子集化，保证公网加载速度。

## 3. 视觉设计（沿用已确认的参考模版 v3）

- **画布**：固定 16:9（1280×720），窗口等比缩放居中；手机竖屏、电脑全屏都不变形。
- **配色**：青海湖蓝 `#2E9BE6`、青 `#21C4B5`、草原绿 `#6FD16F`、油菜花黄 `#FFC93C`、沙金 `#FFB020`、深湖墨 `#1E3C4F`。
- **元素**：圆角厚描边、贴纸、手绘虚线卡、拍立得相框、漂浮云/星、照片周围小星星。
- **玩偶形象**：使用官方卡通形象 `bc7cb84e….png`（替代模版里手绘的 SVG 占位）。

### 3.1 字体方案

- **标题/展示字体**：**站酷快乐体 ZCOOL KuaiLe**，**自托管 + 子集化**——下载源文件，用 `fonttools` 按站点实际用到的字符裁剪，输出 `fonts/zcool-kuaile.subset.woff2`（预计几十 KB），`index.html` 用 `@font-face` 内嵌。
- **正文/数字**：系统字体栈（`PingFang SC / Microsoft YaHei / system-ui`），不额外下载。
- **移除 Google Fonts 依赖**（现模版中的 Google Fonts link 会去掉）。

### 3.2 动效

- **转场**（保留全部 5 种，作为固定效果或页内配置）：滑动 / 推送 / 推进 / 揭幕 / 幕布。
- **每次切换**：线条扫过（蓝/青/黄斜线画入 + 圆点弹出）；元素错峰入场（标签→标题→图→贴纸→星星）。
- **持续动效**：照片周围小星星呼吸闪烁；背景远山、太阳、光点缓慢浮动；标题流动渐变。
- **聊天气泡**：逐条弹出，模拟"消息一条条发进来"。
- **照片本身不持续动效**（按你的要求）。
- **正式版移除左上角转场切换条**。

### 3.3 聊天气泡组件

- 左侧头像：罐罐卡通形象圆形裁剪；右侧白色圆角气泡 + 尖角尾巴。
- 逐条入场动画（延迟错峰），整体置于对应照片**上方**。

## 4. 技术方案

- **单文件 `index.html`**：HTML + CSS + JS 全部内联，无框架、无构建。
- **目录**：
  ```
  aicoding/                 ← GitHub Pages 仓库根
    index.html
    images/                 ← 压缩后的照片
    fonts/                  ← 子集化后的站酷快乐体
    docs/                   ← 设计文档（不影响站点）
    .nojekyll
  ```
- **无外部依赖**（字体与图片全部本地）。
- **兼容**：现代 Chrome / Safari / Edge / 手机浏览器。

---

## 5. 图片处理策略

- 用 Pillow 批量处理：**最长边压到 2000px**、JPEG 质量 ~82、目标单张 < 500KB。
- 原图 10MB / 4.8MB 的几张必须压缩。
- 页面里用 `object-fit: cover` **裁切适配**相框，构图时尽量让罐罐/主体居中不被切掉。
- 原始文件不动，压缩版输出到 `images/`（重命名为短名，如 `d03-shop.jpg`）。

## 6. 部署（GitHub Pages）

1. 在 `D:\研究生\我的\aicoding` 初始化 git 仓库。
2. 推送到 GitHub（需要你在网页上建仓库，或用 GitHub Desktop；本机没装 `gh` CLI）。
3. 仓库 Settings → Pages → Source 选 `main` 分支根目录。
4. 得到 `https://<用户名>.github.io/<仓库名>/` 链接。

> 该目录当前是 Obsidian 仓库（`.obsidian/`），原始素材与文案也混在根目录。部署时把 `index.html`、`images/`、`fonts/` 作为站点内容；其余不影响，另加 `.nojekyll` 避免 Jekyll 处理。
